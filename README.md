# Guggie Reel Website

A fully interactive, free-hosting-ready romantic memory website inspired by the supplied reel reference.

## Upload to GitHub Pages
1. Create a public repository named `Panka8ui.github.io`.
2. Upload `index.html` and the `assets` folder to the repository root.
3. Settings → Pages → Deploy from branch → `main` → `/(root)` → Save.
4. Open https://panka8ui.github.io/

## Customize
Most text is in `index.html`. Photos are in `assets/`.


### 🎵 Soundtrack
The site includes the user-provided `assets/dil-diyan-gallan.mp3`. The soundtrack starts softly when the gift is opened (a user interaction, so browser autoplay restrictions are respected), continues through the memory rooms, lowers for the letter, and fades out in the final room. The top-right music button can pause/play it.
